# Reference Style: @gitlawb on X

Patterns extracted from two timeline captures (Apr 2026 + May 2026).
The CMO talent uses these as the source-of-truth voice analog for
@1clawai posts. Don't copy gitlawb verbatim — extract the *patterns*.

## Identity

- **Handle:** @gitlawb
- **Followers:** 24.1K
- **Companion product:** OpenClaude (9K+ stars by Apr, 26.3K by May)
- **Bio (8 short clauses, single line):**
  > The git layer for the AI-native internet. DIDs over accounts.
  > Every commit signed agent or human.
  > gitlawb.com
- Pattern: tagline + 2 declarative principles + naked link. No emoji,
  no buzzword salad.

## Voice

- Mostly lowercase ("gm", "quick overview for the new arrivals"),
  occasional ALL-CAPS rallying single-word post ("GITLAWBMAXING").
- Confident, low-ego, declarative. Almost no hedging.
- Crypto-native lingo sprinkled in: "wen", "sir/mam", hashtag-as-
  brand-marker (`#openclaude`).
- Coined-term lexicon ("agentic era", "AI-native internet", "first-
  class citizens", "{brand}MAXING"). Repeat the same 3-5 phrases until
  they own them.
- Short sentences. 1-2 line posts are the default.

## Recurring post formats

### 1. Quote-tweet hijack (two subtypes)

**1a. Generic QT** — take a high-signal external post and stamp a
1-line brand thesis on top.
- "Gitlawb is built for the 'agentic era'" QT of Polymarket about
  GitLab job cuts citing the same phrase.
- "Elon loves open source" QT of a 2012 Elon tweet about Hyperloop.

**1b. Big-Issue QT (3-paragraph)** — when the quoted tweet is a
viral grievance (DMCA, deplatforming, key leak, exfil), structure as
*claim → why-it-matters → product-anchor*:

> GitHub can take a repo down with a DMCA.
>
> That's exactly why the Gitlawb thesis matters.
>
> Code is too important to live behind a single choke point.

Why it works: borrowed reach + the topic itself proves the thesis.

### 2. Stats brag

Bare numbers, no commentary, install command at the bottom:

> 140K+ total downloads
> 26.3K stars
> 8.4K forks
> 106 contributors
>
> npm install -g @gitlawb/openclaude

### 3. Milestone announcement

One-line, exclamation, hashtag. Run aggressively — every 1K stars
gets its own post:

> milestone reached! we have now 5K stars for OpenClaude! #openclaude
> breaking: OpenClaude has now 7.6K stars! #openclaude
> OpenClaude is now 9K stars! #openclaude

The repetition is the point — it's a public counter visible in feeds.

### 4. News drop, one-sentence framing

Ship → tweet → why-it-matters in one line.

> Gitlawb is now live on Aerodrome.
> The liquidity pool is set up, giving the Gitlawb ecosystem deeper
> markets, stronger access, and more room to grow.

### 5. Release notes (post + reply thread)

Main post is version + headline metric. Reply with bullet list:

> Open Claude v0.1.7 is live and now 6K stars!
>
> ⤷ (reply)
> New in this release:
>   • guided `/provider` setup
>   • GitHub Models + Atomic Chat support
>   • MCP doctor
>   • better Gemini/OpenAI/Codex compatibility
>   • improved model + reasoning-effort UX
>   • slash-command UI fixes

Bullets use `  • ` (two-space indent, bullet, space) or `  - `. Pick
one and stay consistent.

### 6. Dogfooding post

"We shipped X using our own product Y." Proves the product works on
itself:

> Using the OpenClaude harness with Codex GPT-5.6, we just shipped a
> full UI/UX redesign of the gitlawb node page. #OpenClaude

### 7. Community poll / crowdsourcing

Native X poll, casual lingo:

> wen should we rebrand OpenClaude sir/mam?
>   now (65.4%)
>   later (11%)
>   dont (23.5%)

Or open-ended ask:

> For some legal reasons, we would like to rename OpenClaude.
> Whats your name suggestions?

### 8. Contributor shoutout

Names by handle. Cheap, builds the contributor flywheel:

> shoutout to @crypt0beast & @0x_art for magnificent contributions!

### 9. Threaded thesis ("for the new arrivals")

Opens with a hook, expanded thesis, bullet list:

> quick overview for the new arrivals.
>
> Gitlawb is a decentralized git network where AI agents are first-
> class citizens. cryptographic identity, signed pushes, no central
> authority. agents push code on infrastructure built for them.

### 10. "Read the master plan" / journal CTA

One phrase + link to a long-form journal post on the project site.
Drives traffic without spoiling the payoff:

> Read the master plan
> [link to gitlawb.com/journal/...]

### 11. Single-word rally

"GITLAWBMAXING". One word. No context. Used sparingly to mark
cultural moments (launches, milestones, climaxes).

### 12. Founder repost loop

The brand handle reposts the founder (@kevincodex) building in
public. Adds human credibility without forcing the brand account
to break voice.

### 13. External UGC repost

Repost a third-party user's organic reaction:

> "IT WORKED. I'm in love with free open claude code" — @dhruvtwt_

Pattern: let users tell the story; the brand just amplifies.

## Cadence

- 5-7 posts/day on active days.
- Mix: original (30%) + milestone announcements (15%) + QTs (15%) +
  founder reposts (20%) + UGC reposts (10%) + rallies (5%) +
  release-note threads (5%).
- Cluster days: launches and integrations get 4-6 posts within an
  hour. Star milestones get one post per 1K.

## CTA / repo-driving mechanisms

- Naked `npm install` / `npx -y` commands in posts.
- Bare star + download counts as social proof.
- GitHub link cards (the "From github.com" attachment) instead of
  raw URLs in body text — better preview, larger tap target.
- Project-site journal posts for anything longer than 240 chars;
  the tweet is a teaser, not the full claim.
- Hashtag-as-brand-marker (`#openclaude`) — pick one for the
  primary product and use it on every release / milestone post.
- Founder reposts add a face to the brand.

## What gitlawb avoids

- No threads of marketing copy. Long thoughts go to the journal.
- No emoji-stuffing (occasional emoji is fine; runs of them aren't).
- No "we are excited to announce…" corporate language.
- No mentions of competitors by name (DMCA QT was a person, not a
  rival project).
- No discount/promo tweets.
- No tweet that is just a link with no framing.
