Captured 2026-05-21 from the founder strategy session. This is the
active campaign the CMO talent posts against. Each week has a theme
and a primary CTA — drafts should align to whichever week we're in
when the post is generated.

**North-star metric:** holders count + daily fee revenue (vanity
metrics like followers/stars are secondary).

## Bankr backing — confirmed

**Bankr (Deployer's project) has committed to support 1clawai.** This is
the most important single fact in the campaign. Implications:

- **Cold-outreach problem is solved.** The Day 8 plan ("DM GitLawb
  founder") becomes "ask Bankr to make the intro." Bankr is the
  connector of the entire ecosystem — a warm intro from them lands
  every time.
- **Reciprocal mentions accelerate.** Anything we publish that
  Bankr can amplify, they probably will. Coordinate launch posts
  so Bankr can repost on the same day.
- **"Backed by Bankr" positioning** is legitimate social proof —
  but use sparingly, never as the lead. Once per major announcement,
  embedded as a fact, not a brag. Bankr-ecosystem traders already
  know what backing means.
- **Joint-stream / Spaces probability goes way up.** Pitch a "Bankr
  agentic dev stack" Space with Bankr + GitLawb + 1Claw on the
  same stage. Bankr can pull both other voices.
- **Editorial coverage gets a stronger angle.** Pitches to Gate
  Learn, Zeneca, etc. can lead with "Bankr-backed security layer
  for the agentic stack" — much hotter hook than "interesting
  MCP server."

What does NOT change:

- The product still has to be real. Bankr backing is a force
  multiplier, not a substitute for the reference agent + magnet
  tool.
- We still avoid "pump" language. Backing makes us look serious,
  not bullish on price.

## Bankr-ecosystem positioning

Bankr's pitch: "agents launch tokens, earn fees, fund their own
compute." The 1Claw / 1clawai pitch translated for that audience:

> The secrets layer for self-sustaining agents on Bankr.

The 4-layer stack we anchor to in every post:

- **GitLawb** — code + identity (DIDs, signed pushes)
- **Bankr** — wallet + token launch + fee accrual
- **LLM providers** — Anthropic, OpenAI, Gemini via OpenClaude
- **1Claw** — secrets, signing, TEE-inspected inference

We are the missing security layer. Every post should reinforce that
positioning.

## Concrete gaps vs GITLAWB (from on-chain analysis)

- **No CEX flow.** GITLAWB has continuous MEXC market-maker flow;
  1CLAWAI does not. Resolving this is the highest-leverage single
  action — campaign Week 2 starts the listing process.
- **Approve calls dominate.** Recent on-chain activity is wallets
  setting up to swap but not actually trading. We need posts that
  drive *trades*, not just curiosity.
- **No editorial coverage.** GITLAWB has a Gate Learn write-up. We
  need at least one equivalent — campaign Week 3 pushes for it.
- **No reciprocal ecosystem mention.** OpenClaude README lists
  Bankr, Atomic Chat, GitLawb as ecosystem partners. We aim for
  the fourth slot via a PR.

## What we never post (campaign rules)

- **Don't pitch GitLawb as "help us pump."** Position as "your
  agents need a secrets manager, here's the integration."
- **Don't claim integrations that aren't shipping.** The Bankr
  ecosystem has antibodies for parasitic name-drops.
- **Don't lean into the "claw" meme.** Multiple meme-grade "claw"
  tokens exist (ClawBeacon, ClawVault, CLAUNCH, etc.) — we
  differentiate as the canonical *security primitive*, not as
  another claw token.
- **No coordinated buying language.** Treasury alignment is fine
  if publicly disclosed; pump signals are not.
- **No promises about MEXC / Gate Learn before they land.** Soft
  mentions only ("listing applications submitted") until the
  announcement is real.
- **No price talk in brand-voice posts.** Founder can talk about
  fees + holders; brand handle stays on product narrative.
